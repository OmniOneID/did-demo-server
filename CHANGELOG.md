# Changelog

## [Unreleased] (v3.0.0)

### 🚀 New Features
- OID4VC issuance tab (OID4VCI credential offer QR code and Tx Code)
- VP submission follows the protocol type of the policy (OpenDID VP or OID4VP) and shows the submitted claims for OID4VP
- 'Skip' link in the claim input popup to issue a VC with claim data generated by the Issuer

### 🔧 Changes
- Server version 3.0.0 (`did-demo-server-3.0.0.jar`)

### 🐛 Bug Fixes
- The OID4VC screens no longer say '4-digit Tx Code'. The Issuer issues a 6-digit Tx Code.

## v2.0.0 (2025-05-30)

### 🚀 New Features
- Demo Server

    - Added user information input feature by VC schema (including ZKP) for dynamic VC plans
    - Added server configuration functionality
    - Added user information storage feature (JSON) within the server
